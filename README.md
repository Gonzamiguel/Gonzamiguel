### Sobre mí

Soy desarrollador full stack y estudiante avanzado de la **Licenciatura en Ciencia de Datos**. Trabajo en la intersección entre la ingeniería de software y el modelado analítico: construyo aplicaciones web listas para producción y diseño modelos predictivos que responden a problemas concretos de negocio.

Mi enfoque es **End-to-End**: no concibo los modelos de Machine Learning aislados en notebooks locales, sino integrados en arquitecturas de software escalables, con consultas SQL optimizadas, APIs robustas e interfaces accesibles.

- 🔭 **Actualmente:** Desarrollando plataformas web para clientes e investigando modelos de clasificación y scoring en datasets del sector financiero y logístico.
- 🎯 **Objetivo:** Roles corporativos en Data Science & Machine Learning y consultoría técnica en arquitectura de software.
